# CATopalian Combine JS Format for MD
Double click on this bat file to copy all JS file contents into one md file that is formatted with JS syntax highlighting!

In other words, we make a book from our scripts folder instantly by double clicking our bat file!

---

### How to Download this App
1. Click the green Code Button on this github page
2. Choose Download ZIP
3. Save the Zip File
4. Extract All
5. Double click the bat file to copy all JS file content into one formatted MD file!
